# リズムスピーカー商店｜定番補充・リピート購入商品戦略 v1.0

決定日: 2026-11-16
判断根拠: ユーザーより「みんなが毎週・毎月買う消耗品をいつものメニューに掲載し、購入クリックを増やす」方針追加
適用: ①商品開拓の今後の選定優先順位。④公開サイト改修は別チャット。既存公開サイトに無断変更しない。

## GOAL
一度きりのガジェット紹介でなく、消耗品を「補充するために戻ってくる」商店にする。クリックではなく、継続購入・紹介料実績・訪問リピートを最終評価する。Amazon通常商品URLは不要、本人発行の正式アフィリエイトリンクのみ最終購入導線に使う。

## 初期の新規選定構成案（100件換算）
- 45件: 日用品・消耗品（紙・洗濯・台所・掃除・衛生）
- 25件: 食品・飲料（コーヒー・紅茶・お米・冷凍食品など。保存性や配送条件も確認）
- 20件: 便利家電・ガジェット（使用体験・課題解決があるもの。買い替え需要）
- 10件: 趣味・季節もの（タップ、文化、冬の防寒など）
これは候補配分でありREADY目標や公開数を保証しない。現行42件の公開/READY比率に遡及適用しない。

## 定番補充棚の6分類
1. 毎日の紙もの：トイレットペーパー、ティッシュ、キッチンペーパー
2. 洗濯・衣類ケア：液体洗剤の詰め替え、柔軟剤、酸素系漂白剤
3. 台所のストック：食器用洗剤、スポンジ、ラップ、アルミホイル、ごみ袋
4. 掃除の消耗品：床用ドライ/ウェットシート、粘着クリーナー替え、浴室・トイレ掃除用品
5. 衛生・身だしなみ：ハンドソープ、歯みがき、歯ブラシ、シャンプー詰替え
6. 食品・飲料：コーヒー豆、茶葉、米、乾物、調味料、冷凍ストック
消費頻度（週・月）は一般的な目安であり、個別家庭に必ず当てはまるとは限らない。

## 商品選定スコア v1.0
100点満点: 買い足し頻度25、国内調達と継続販売20、使い勝手/顧客課題20、売れ筋用途/価格耐性15、根拠とスペック確実性10、運用負担10。
個別SKUが未確定の場合はCANDIDATE_RESEARCHに止める。本人所有品とは断定しない。過去実績があればレビュー・クリック・紹介料を使い入替判断する。

## 画面構成（④の実装案であり未承認）
「いつもの買い物」入口 → 6つの用途棚 → 商品カード（型番、入数、なぜ便利、注意、購入リンク）
「また買う」導線は最初は通常の固定カテゴリリンクのみ。会員・リマインダー・価格監視・新DBを導入しない。
商品をリストに載せるだけでAmazon定期おトク便の利用や紹介料が保証されるものではない。

## 現在バッチ優先度の変更
BATCH-20261116-02 の残り6枠は、上記の補充定番品を最優先。以前選定した未登録ハードウェア候補（Lock Ultra、Bot、センサー、Space One、ソーラーパネルなど）は次期へ繰り下げる。
選定済みでもAmazon公式アフィリンクと商品同一性が確認されるまで公開しない。

## 効果測定
最小限の記録: 商品ID、カテゴリ、公開日、正式リンク、実績の得られるクリック、紹介料、購入頻度の推定区分、差替え判断。
購入者ごとの行動は観測できない可能性があるため「同じ人が毎月購入した」と推測で断定しない。効果はAmazonアソシエイトの集計結果と公開データで検証。
