STRETCH CLASS｜BEGINNER FRIENDLY

前屈も、開脚も。
身体を知る入口に。

「もっと前屈したい」「開脚を広げたい」。そんな分かりやすい目標から始めて、身体を観察し、動かし、伸ばし、最後にもう一度変化を確認する60分のストレッチクラスです。

Produced by 古庄里好Main Instructor：MiFa-san
初級60分を見るLINEで体験を相談する

CLEAR GOALS

「柔らかくなる」を、分かりやすい目標から始める。

初級では完成形を急ぎません。前屈・開脚など、変化が見えやすい動作を入口にして、自分の身体の状態と動きのつながりを知っていきます。

前屈

床へ少しずつ近づく。股関節や骨盤を含め、身体全体の動きを観察する。

開脚

無理に180°を狙わず、自分に合う安全な範囲を少しずつ広げる。

バランス

三角振子バランスで、呼吸・荷重移動・各関節の動きをつなげる。

全身

足首から肩まで、下から順番に身体を観察して動かす。

3 LEVEL SYSTEM

ひらく → できる → 使う。

01

初級｜STRETCH BASIC

身体をひらく

初心者向けの入口。三角振子バランスと基本ストレッチで、身体を観察しながら動かします。

  • 姿勢と呼吸のチェック
  • 足首から肩までの関節編
  • 前屈・開脚につながる基本ストレッチ
  • Before / Afterで変化を確認
02

中級｜FLEXIBILITY & MOBILITY

できる身体をつくる

前屈・開脚・深いスクワットなど、具体的な目標達成を狙う段階です。

  • テーマ別の可動域トレーニング
  • Dynamic Mobility
  • Active ROMと軽い筋力
  • Before / Afterで変化を確認
03

上級｜BODY CONTROL

身体を理解して使う

柔軟性だけを目的にせず、バランス・荷重・制御・日常動作やダンスへ統合します。

  • Mobility / Stability / Control
  • 足部・股関節・骨盤・胸郭の連動
  • 生活・運動への実践的な翻訳
  • 自分の身体を観察して調整する力

STRETCH BASIC｜60 MINUTES

初級60分の流れ

前半30分で身体を観察して動かし、後半27分でストレッチ。最後の3分でもう一度身体を確認します。

前半 30分

CHECK & TRIANGLE PENDULUM

立位姿勢チェックと三角振子バランスで、足首から肩まで順番に身体を動かします。

後半 27分

STRETCH FLOW

足首・前腿・ハムストリング・臀部・背骨へ進み、前屈と開脚につなげます。

最後 3分

AFTER CHECK

立位・呼吸・軽い前屈で、最初との違いを確認します。

  1. 0–5分

    1｜立位・姿勢チェック

    目・耳・肩・腰・膝・くるぶしの高さを観察。呼吸に合わせて三角振子バランスを行い、締めに軽い前屈を確認します。

  2. 5–30分

    2｜三角振子バランス・各関節編

    足首 → 膝 → 股関節 → 骨盤 → 背骨 → 胸郭 → 肩の順番で進みます。

    • 膝：手またはヨガブロックを膝裏に挟む
    • 股関節：手を鼠蹊部に当てる（順手・逆手）
    • 骨盤：手を腰に当てる（順手・逆手）
    • 背骨：腰椎・ウエスト周辺に手を当てる（下向き合掌、腹部・背中）
    • 胸郭：胸・ウエスト周辺に手を当て、手の向きや接触位置を変えながら呼吸と動きを感じる
  3. 30–57分

    3｜ストレッチフロー

    足首ストレッチ → 前腿 → ハムストリング（前屈） → 臀部（開脚） → Cat & Cow → Small Turtle。最後は急がず、ゆっくり身体を起こします。

  4. 57–60分

    4｜AFTER CHECK

    立位・呼吸・軽い前屈をもう一度行い、レッスン前後の変化を観察します。

IMPORTANT

全員が180°開脚することを目標にはしません。

身体の形や現在の状態には個人差があります。痛みを我慢して形を作るのではなく、自分の安全な可動域を広げ、動かせる範囲として身につけることを重視します。鋭い痛み、しびれ、強い違和感がある場合は、その動作を中止してください。
