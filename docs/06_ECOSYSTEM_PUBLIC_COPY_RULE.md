# Ecosystem Public Copy Rule

Public copy answers these questions in this order:

1. What can I do here?
2. Is this for me?
3. Where will this link take me?

Avoid exposing implementation/governance vocabulary unless the user needs it to use the service.

## Avoid in public cards

- repository architecture
- internal division ownership
- Source of Truth terminology
- OS management process
- rollout/development-state commentary
- platform governance explanations

## Keep when user-relevant

- Member-only / continuing-user distinction
- External shop distinction when it prevents confusion
- Booking / trial destination
- Service availability
- Rights/licensing limitations when they affect what the user can actually purchase or use

Public clarity takes precedence over explaining the internal operating model.
