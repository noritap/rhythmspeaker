## ユーザージャーニー

- 新規: 初回体験 1,000円 → 体験案内 → 申込
- 1回利用: ビジター 3,500円 → レッスン日程 → スタジオへの連絡
- 継続: 10/25/50回プラン比較 → 選択プラン名入りLINE相談
- 既存会員: 手順後のRS Walletリンク → 残高・利用履歴

- 30分クラス・個人レッスン・ワークショップなど料金が異なる場合がある旨を維持。

- 申し込み・LINE起動・クリックだけでは予約確定ではない。
- 未確認の有効期限・支払方法・キャンセル・返金条件を断定しない。
