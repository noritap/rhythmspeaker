# Ecosystem UX Risk Register

## Risk: breaking generated navigation
Mitigation: do not edit RS-NAV-2 blocks in the first patch; run strict navigation audit.

## Risk: hiding useful service-role distinctions
Mitigation: simplify operator wording, but keep user-relevant member/shop/external distinctions.

## Risk: decorative redesign without evidence
Mitigation: preserve UI v2 until rendered verification identifies a visual defect.

## Risk: declaring completion from source inspection
Mitigation: rendered desktop/mobile and post-merge public verification remain mandatory gates.
