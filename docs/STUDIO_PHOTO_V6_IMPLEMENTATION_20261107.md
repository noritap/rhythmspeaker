## 3. 残る最小作業

1. 公開用ZIPをローカルで展開。
2. 掲載許可、私物・画面・人物等の写り込みを目視確認。
3. 最新 `noritap/rhythmspeaker` のローカルリポジトリで
   `sh INSTALL_TO_RHYTHMSPEAKER.sh /path/to/rhythmspeaker` を実行。
4. 6枚の `assets/images/studio/library/2026-11/web/*.webp` と
   `data/studio-photo-library-public.json` をセットでcommit/PR/main統合する。
5. GitHub Pagesで実画像、クリックでの拡大、モバイル表示、アクセシビリティを検証する。

パブリックマニフェスト `data/studio-photo-library-public.json` の `published` は
画像が未登録の現在は空。上記ZIPの完成マニフェストを同時にコミットすると、共通JSが画像の読み込み成功時のみ対応する `img` と拡大リンクを置換する。

## 4. レンダリングの契約

- 本番HTMLは既存実写を `src` に保持する。
- `data-studio-photo-id` がある写真だけが候補。
- 共通JSが公開マニフェストを読んで、存在する写真のみ置換する。
- マニフェストに未承認のファイルを混ぜない。
- 読み込み失敗時は既存写真とALTを保持。
- 合成写真は実写として表示しない。実際のレッスン風景との誤認を防止。
- 写真だけから寸法・間取り・最大収容人数を推定しない。

## 5. 完了の判定

コード実装と画像ファイルの実アップロードは異なる工程。
このPRの成功条件は静的ページの不具合を増やさず、新画像配置先を実装すること。
写真が実際に表示されたかどうかは、6枚のコミットと本番URL検証をもって別途判定する。
