## 2. 料金と利用時間

| プラン | 税込等の明示は契約確認要。公開料金 | 対象・時間 | UI |
|---|---:|---|---|
| 通常レンタル | ¥3,500／時間 | 原則23:00終了。開始時刻候補は22:00まで | 終了時刻超過を拒否。22:00開始は1時間へ自動調整 |
| 平日朝割引 | ¥1,500／時間 | 平日7:00〜12:00の利用に限る | 曜日・時間内の収まりをチェック |
| 深夜6時間パック | ¥4,000／6時間 | 選択日0:00〜6:00（前日24:00から） | 開始日を日付として選択、6時間固定 |
| シェアレンタル | ¥500／時間 | 非貸切。実施条件は個別確認 | 「貸切ではない」を表示 |

`STARTER SUPPORT` は利益連動制度（一般レンタルの固定料金とは別）。対象利益の30%等の条件は現行の詳細情報を優先し、相談内容に反映する。

## 3. Googleカレンダーの扱い

- 予約フォームで4プランを選んだ後、希望日選択の**直前**に「スタジオの予定から時間を探す」を設置。
- 「別画面で週間予定を見る」で、ユーザーが提供したGoogleカレンダー（複数表示元の週表示）を開く。
- 「このページに週間予定を表示」を開いた場合のみ、埋め込み`iframe`を読み込む。
- **Googleカレンダーには予約台帳のライブな空き確定判定がない。** 無予定時間の表示は利用可能性を保証しない。
- カレンダー側の公開設定によっては第三者に表示されないため、外部リンクへ誘導するフォールバックと、一般利用者視点の実画面確認が必要。
- 相互の選択日自動同期は未実装。予約フォームで日時を選び、最終確認はLINE。

## 6. 品質ゲートと禁止事項

- 予約導線に誤った空き保証・即時予約確定・決済完了表示を入れない。
- 料金・日付・時刻の選択が変わったら相談サマリーとLINEの相談文を一致させる。
- 特別プランの時刻ガイダンスを、選択中のプランと一致させる。
- 320/375/390/430px・PC幅で、カレンダー横スクロール・はみ出し・重なりを確認。
- テストが成功しても、LINE送信完了や外部カレンダーの第三者閲覧成功を保証したことにはしない。
- PR→CI→main統合→公開GitHub Pagesの実表示確認を別々に記録。
