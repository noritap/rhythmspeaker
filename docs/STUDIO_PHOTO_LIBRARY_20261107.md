## 1. 伝える順番

レンタルページの役割は「利用する空間が分かる → 条件が分かる → 日時を相談できる」こと。トップから下まで24枚並べない。

| 段階 | 画面 | 写真の役割 |
| --- | --- | --- |
| L0 | ファーストビュー | スタジオ内観の1枚で用途を認識。現行の実写を維持 |
| L1 | レンタル主要ギャラリー | フロア全景 → 鏡・フロアの別角度 → シューズ。まず3枚 |
| L2 | 展開式の別角度 | スタジオ別角度を任意で拡大できる |
| L3 | 設備・アクセス詳細 | 更衣室・シューズ棚・入口から地下階段（必要なページのみ） |
| L4 | 内部参照・画像制作 | 私物・機器画面・ポスター・トイレ・収納等。原則公開しない |

生徒や講師を加えたイメージ写真は、原本実写から床・鏡・照明・受付・動線の特徴を受け継ぐ。実際のレッスンやイベントの記録写真であるかのようには表示しない。合成と実写は別ID・別フォルダで管理する。
