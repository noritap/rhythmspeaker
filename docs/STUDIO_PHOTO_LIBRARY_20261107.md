# Rhythm Speaker｜スタジオ写真ライブラリ（2026-11-07）

ユーザーから提供されたスタジオ実写写真20枚の**分類・検索・アップロード先の仕様**です。

## 重要：現在の状態

- ✅ 20枚の分類と写真台帳をGitHubで管理：`data/studio-photo-library.json`
- ✅ 原本を保持し、WebP変換版とサムネイルを作成したZIPをチャット内で生成
- ⛔ **画像ファイル20枚そのものはまだGitHubにはアップロードされていません。** この環境ではチャット添付のバイナリをGitHubコネクタに引き渡せないためです。
- ⛔ 写真パスは予定場所です。画像がアップロードされるまでは公開ページから参照しないでください。

## 再利用のルール

1. 新規ページでは台帳から写真を選ぶ。重複して別ファイル名でコピーしない。
2. 公開前に画面・人物・私物などの写り込みと公開許可を確認する。
3. レンタル・教室紹介ページではフロアの広角写真を優先し、トイレや収納の写真は詳細設備案内へ配置する。
4. 元画像から物件の正確な図面、寸法、バリアフリー性能、最大収容人数を断定しない。
5. 将来ZIPをアップロードしたら、写真台帳の`asset_state`を`UPLOADED`に変更して参照URLを検証する。

## 残る最小作業

ZIP内の`originals/`、`web/`、`thumbnails/`を上記のGitHubパスに配置。画像リンクを検証後、必要なページでのみ使用する。
