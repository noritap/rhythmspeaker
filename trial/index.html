HOW TO START

予約から当日まで、3ステップ。

01 / REQUEST

希望を伝える

体験申し込みフォームから、経験や興味のあるクラス、希望日時を送ります。クラスは未定でも申し込めます。

02 / CONFIRM

返信で日時を調整する

スタジオからの「予約確定」の返信をもって予約が成立します。

03 / FIRST SOUND

15分前にスタジオへ

シューズ・ウェアを選び、基本の姿勢と音の出し方から。続け方は体験後に相談できます。

完全初心者でも大丈夫ですか？

はい。初心者向けの「STEP 超初級」では、基本的な立ち方、膝の使い方、足のどの部分で床を叩くかから練習します。タップを一度も経験したことがない方も参加できます。

50代・60代からでも始められますか？

はい。50代・60代から始めたい方もご相談ください。年齢や体力への不安を確認しながら、基本の姿勢や音の出し方から進めます。

手ぶらで行っても大丈夫ですか？

はい。タップシューズと動きやすいウェアを無料でレンタルできます。体験用のシューズやウェアを購入してから来る必要はありません。
