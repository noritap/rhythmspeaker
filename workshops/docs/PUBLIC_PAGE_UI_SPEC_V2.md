# Rhythm Speaker Workshop Manager — Public Page UI/UX Spec v2

## Objective

ワークショップ参加者がスマートフォンで「内容理解 → クラス比較 → 不安解消 → 予約」まで迷わず進める公開ページを共通テンプレート化する。

## Conversion flow

1. ファーストビューで日時・会場・価格帯・受付状態を把握
2. クラスカードで時間・レベル・料金・残席を比較
3. ワークショップの価値・対象者を理解
4. 講師・会場・持ち物・FAQで不安を解消
5. 固定CTAまたは各クラスCTAから予約フォームへ遷移
6. 予約完了後に予約番号と支払い案内を表示

## Media roles

- `coverImage`: 一覧カード 16:9
- `heroImage`: 詳細ファーストビュー。人物・動きが伝わるクロップ
- `flyerImage`: 元フライヤーを全体表示。モーダル拡大対応
- `instructorImage`: 講師紹介
- `ogImage`: LINE / SNS共有
- `galleryImages`: 会場・レッスン風景など

元画像は情報テキストを読ませる用途ではなく、訴求・信頼・世界観づくりに使う。日時・料金・住所・クラス情報は必ずHTMLで保持する。

## Public event page sections

### 1. Event Hero
- 予約受付中バッジ
- 開催日
- イベント名
- サブコピー
- 講師名
- 会場
- 価格帯
- メインCTA「クラスを選んで予約」
- ヒーロー画像

### 2. Sessions
- クラス名
- 時間
- 分数
- レベル
- 料金
- 定員 / 残席
- CTA「このクラスを選ぶ」
- セット商品は強調表示

### 3. Value / Who it is for
- 学べること
- 対象者
- ワークショップの特徴

### 4. Instructor
- 講師写真
- 名前
- プロフィール
- メッセージ

### 5. Flyer
- フライヤー縮小表示
- タップでモーダル拡大
- CTA再配置

### 6. Venue / Access
- 会場名
- 住所
- 最寄駅案内
- Google Maps外部リンク（設定時）

### 7. Bring / Policy / FAQ
- 持ち物
- シューズレンタル
- キャンセルポリシー
- FAQアコーディオン

### 8. Reservation form
- 参加クラス
- 氏名
- 電話
- メール
- タップ経験
- シューズ持参 / レンタル
- サイズ
- 備考
- 同意

### 9. Mobile Sticky CTA
- 画面下に常時表示
- 現在選択中の価格または「クラスを選ぶ」
- 予約フォームへスクロール

## Mobile UX rules

- 主要CTA高さ44px以上
- 重要情報を画像内文字に依存しない
- 1カラム優先
- フォーム入力時に固定CTAが邪魔にならない余白を確保
- 料金・残席は視線走査しやすい右側または独立KPIで表示
- 画像は `object-fit: cover` と `object-position` で用途別クロップ
- 画像の代替テキストを設定
- 空データのブロックは非表示にしてページ密度を維持
